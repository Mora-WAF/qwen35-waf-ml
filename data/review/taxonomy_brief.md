- `sqli_classic` (L7_INJECTION): Classic SQL injection: quote, boolean, UNION or comment tokens altering a query in plain form. The one URL-encoding layer that carries it in a path, query or cookie is transport, not obfuscation. Not: Encoded or obfuscated SQL belongs to sqli_obfuscated; Operator injection into document stores belongs to nosqli; SQL keywords in prose or docs with no query-bound input.
- `sqli_obfuscated` (L7_INJECTION): SQL injection hidden through encoding, inline comments, case or whitespace tricks, or nested decoding. Not: Plain unencoded SQL belongs to sqli_classic; Plain SQL whose only encoding is the transport URL-encoding of a path, query or cookie belongs to sqli_classic; Header framing tricks belong to http_request_smuggling.
- `nosqli` (L7_INJECTION): Operator injection into document-store queries, such as MongoDB operators in JSON or bracket parameters. Not: SQL syntax belongs to sqli_classic or sqli_obfuscated; Operator keys accepted by a documented filter API.
- `xss_reflected_stored` (L7_INJECTION): Script or markup injection reflected in a response or persisted for later rendering. Not: Payloads that run only via client-side DOM sinks belong to xss_dom_polyglot; Spreadsheet formula payloads belong to csv_formula_injection; Escaped output displayed as literal text.
- `xss_dom_polyglot` (L7_INJECTION): Payloads that execute through client-side DOM sinks or polyglot parsing across several contexts. Not: Server-reflected payloads with no client sink belong to xss_reflected_stored; Static JavaScript assets with no attacker-controlled fragment.
- `rce_cmd_injection` (L7_INJECTION): Command separators or substitution injected into input passed to a shell or process execution. Not: Traversal without command syntax belongs to path_traversal_lfi; Template expression evaluation belongs to ssti; Command text in help pages or docs; Executable files delivered by upload belong to malicious_file_upload_webshell; Shell commands in an AI agent tool call belong to mcp_agentic_tool_abuse.
- `ssti` (L7_INJECTION): Server-side template injection where input is evaluated by a template engine expression context. Not: Client-side template injection in browser frameworks belongs to xss_dom_polyglot; Literal braces in JSON or code samples; Command execution belongs to rce_cmd_injection.
- `xxe` (L7_INJECTION): XML external entity or DTD abuse that makes an XML parser reference external resources or local files. Not: Plain XML with no DOCTYPE or ENTITY declarations; Fetch of internal addresses with no XML parser belongs to ssrf_cloud_metadata.
- `deserialization` (L7_INJECTION): Untrusted serialized object payloads sent to deserializers that can trigger gadget chains. Not: Plain JSON with ordinary data fields; Tokens that are only decoded with no deserializer path belong to jwt_auth_bypass.
- `crlf_header_injection` (L7_INJECTION): CR LF or encoded line breaks in a header value that inject extra response or request headers. Not: Framing conflicts via Content-Length or Transfer-Encoding belong to http_request_smuggling; Line breaks in form text bodies with no header context.
- `ldap_xpath_injection` (L7_INJECTION): Filter or expression injection into LDAP or XPath lookups through unescaped input. Not: SQL-style quoting in database queries belongs to sqli_classic; Plain wildcard search text with no filter syntax.
- `csv_formula_injection` (L7_INJECTION): Spreadsheet formula prefixes in stored or exported fields that execute when opened in a spreadsheet. Not: Negative numbers or dashes in ordinary text; Script tags rendered in a browser belong to xss_reflected_stored.
- `malicious_file_upload_webshell` (L7_INJECTION): Uploads that place server-executable content (script files, double-extension or content-type-mismatched files, handler-override configs) where the server can execute it. Not: Uploaded HTML or SVG with client-side script belongs to xss_reflected_stored; Entity declarations in uploaded XML or office files belong to xxe; Source files uploaded to a code store that serves them as non-executable text.
- `path_traversal_lfi` (L7_API_PROTOCOL): Directory traversal or local file inclusion that reads or includes files outside the intended path. Not: Command execution after traversal belongs to rce_cmd_injection; Relative paths that stay inside the allowed root; Traversal in an AI agent tool call belongs to mcp_agentic_tool_abuse.
- `ssrf_cloud_metadata` (L7_API_PROTOCOL): Server-side fetch targets pointing at internal networks or cloud metadata addresses. Not: Redirect parameters that only send users to external sites belong to open_redirect_cors; XML entity fetches with no fetch target belong to xxe; Internal fetch targets in an AI agent tool call belong to mcp_agentic_tool_abuse.
- `http_request_smuggling` (L7_API_PROTOCOL): Conflicting or duplicate framing headers that make front-end and back-end parsers disagree on request boundaries. Not: Header value injection with no framing conflict belongs to crlf_header_injection; Text templates for HTTP/2 with no raw frame fixture.
- `graphql_abuse` (L7_API_PROTOCOL): Abusive GraphQL operations such as deep nesting, alias batching, or introspection and query-cost abuse. Not: Queries within documented depth and cost limits; Authorization failure on one object belongs to bola_idor_enumeration.
- `jwt_auth_bypass` (L7_API_PROTOCOL): Token verification bypass: a JWT or comparable signed bearer token accepted without valid verification, either because it is forged, unsigned or algorithm-confused, or because it exploits a verifier flaw (weak, default or empty secret; partial signature or claim checks; exp, nbf, aud, iss or token_use validation or type-coercion errors; attacker-controlled key sources). Not: Decoding a token for inspection is not an attack; Session fixation without token forgery; A correctly verified token whose claims grant more than the caller should have is an authorization flaw: bola_idor_enumeration, bopla_mass_assignment or bfla_admin_function_probing.
- `bola_idor_enumeration` (L7_API_PROTOCOL): Sequential or guessed object identifiers used to reach resources that belong to other subjects. Not: Sequential IDs alone with no authorization context; Credential guessing belongs to credential_stuffing_bruteforce; Writing unauthorized properties of the caller's own object belongs to bopla_mass_assignment; Calling functions above the caller's role belongs to bfla_admin_function_probing.
- `open_redirect_cors` (L7_API_PROTOCOL): Redirect targets or CORS origins that reflect attacker-chosen cross-origin values. Not: Server-side fetch of internal addresses belongs to ssrf_cloud_metadata; Same-origin redirects.
- `websocket_grpc_abuse` (L7_API_PROTOCOL): Abuse of WebSocket upgrades or gRPC streams, such as message flooding, origin bypass, or unauthorized subscriptions. Not: Ordinary HTTP requests with no upgrade or stream framing; Normal long-lived streams at expected message rates.
- `bopla_mass_assignment` (L7_API_PROTOCOL): Object-property authorization abuse: a create or update request sets properties the caller may not write (role, owner, price, balance, verification flags) through mass assignment. Not: Access to another subject's whole object by identifier belongs to bola_idor_enumeration; Calling an endpoint reserved for a higher role belongs to bfla_admin_function_probing; Writes to fields the object schema marks writable for the caller's role.
- `bfla_admin_function_probing` (L7_API_PROTOCOL): Function-level authorization abuse: a caller with a lower role invokes or probes administrative or privileged functions (admin routes, management methods, internal operations). Not: Same-role access to another subject's object belongs to bola_idor_enumeration; Privileged properties smuggled into an allowed write belong to bopla_mass_assignment; Admin routes called by a caller whose role permits them.
- `race_condition_toctou_burst` (L7_API_PROTOCOL): Near-simultaneous bursts of the same state-changing request (redeem, transfer, vote, withdraw, apply-discount) timed to win a check-then-act race. Not: Bursts against read-only or idempotent routes, or requests sharing one idempotency key; Login attempts across many accounts belong to credential_stuffing_bruteforce; Sustained high-rate traffic with no single repeated state change.
- `llm_prompt_injection` (L7_AI_MODERN): Untrusted input that tries to override an LLM's instructions, leak its system prompt, or hijack tool use. Not: Quoted security discussion or research text is benign; Ordinary user questions with no instruction override; Agent tool calls, tool descriptions or tool results belong to mcp_agentic_tool_abuse.
- `prototype_pollution` (L7_AI_MODERN): Keys such as __proto__ or constructor.prototype used to modify object prototypes in merge or parse paths. Not: Ordinary field named constructor in a data schema; Plain JSON field names with no prototype path.
- `web_cache_poisoning` (L7_AI_MODERN): Unkeyed header or parameter input reflected into a cacheable response so other users receive poisoned content. Not: Reflection in responses that are not cacheable; Ordinary cache-busting query strings.
- `mcp_agentic_tool_abuse` (L7_AI_MODERN): Abuse of an AI agent's tool layer (MCP JSON-RPC or similar): tool calls whose arguments leave the granted scope (files, internal URLs, shell), poisoned tool descriptions, or tool output that steers the agent into unrequested calls. Not: Untrusted text that only tries to override the model's instructions, with no tool call or tool metadata, belongs to llm_prompt_injection; Tool calls inside the manifest's granted scope for the user's task; Traversal, SSRF or command payloads sent to an ordinary HTTP endpoint with no agent tool layer.
- `syn_flood_ddos` (L4_NETWORK_FLOW): SYN-dominant bursts and half-open connection patterns aimed at exhausting a target. Not: Normal bursts with completed handshakes; Sweeps across many destinations belong to port_scan_recon; Stream resets or CONTINUATION floods over few established connections belong to http2_rapid_reset_continuation.
- `udp_amplification` (L4_NETWORK_FLOW): Spoofed or reflected UDP traffic from amplifying services, with large response-to-request ratios aimed at a victim. Not: Ordinary DNS resolver traffic at normal sizes; DNS tunneling payloads belong to dns_tunneling_exfil.
- `slowloris_slowhttp` (L4_NETWORK_FLOW): Many connections held open with very slow partial requests or reads to exhaust server connection slots. Not: Long-polling or streaming clients with steady activity; High-volume SYN bursts belong to syn_flood_ddos.
- `credential_stuffing_bruteforce` (L4_NETWORK_FLOW): Repeated login attempts across many accounts or passwords from distributed or rotating sources. Not: A single user mistyping a password a few times; Token forgery belongs to jwt_auth_bypass.
- `port_scan_recon` (L4_NETWORK_FLOW): Systematic probing of many ports or hosts with minimal payloads to map exposed services. Not: Monitoring tool sweeping known hosts on fixed ports; Single-port connection bursts belong to syn_flood_ddos.
- `c2_beaconing_anomaly` (L4_NETWORK_FLOW): Periodic low-volume callbacks with regular intervals and consistent sizes, suggesting command-and-control check-ins. Not: Scheduled telemetry from known agents with documented intervals; Data carried in DNS belongs to dns_tunneling_exfil.
- `dns_tunneling_exfil` (L4_NETWORK_FLOW): DNS queries carrying encoded data in long or high-entropy labels, or unusual high-volume record types. Not: Normal lookups of short labels; Periodic check-ins with no encoded payload belong to c2_beaconing_anomaly.
- `tls_ja4_ua_spoofing` (L4_NETWORK_FLOW): TLS fingerprint or user agent that does not match the measured client stack, used to impersonate a browser. Not: A fingerprint mismatch explained by a known middlebox (TLS inspection proxy, carrier optimizer) is not malicious; A mismatch without impersonation behaviour (UA rotation, automation-rate requests) is not enough; Standard clients with unusual but benign fingerprints.
- `http2_rapid_reset_continuation` (L4_NETWORK_FLOW): HTTP/2 stream-level floods over few connections: streams opened and immediately reset (rapid reset), or long CONTINUATION frame sequences that never end the header block. Not: SYN-dominant bursts across many connections belong to syn_flood_ddos; Browsers cancelling a few streams on navigation or media seeking; Slow partial requests that hold connections open belong to slowloris_slowhttp.
- `benign_standard_traffic` (BENIGN): Ordinary network flows and HTTP requests to common services, the default negative class. Decision rule for benign HTTP: no injection-, script-, shell-, template- or traversal-lookalike content in any field -> this class; lookalike content -> benign_hard_negative_search if it is end-user search/filter text, otherwise benign_hard_negative_dev. Not: Any observation with attack-class evidence belongs to that attack class; Benign requests whose fields carry attack-lookalike content belong to benign_hard_negative_dev or benign_hard_negative_search; Legitimate traffic whose rate resembles a flood or scan belongs to benign_high_rate_legit.
- `benign_hard_negative_dev` (BENIGN): Benign requests whose body or parameters carry attack-lookalike content (SQL, script or markup, shell, template syntax, paths, encoded blobs, payload text) as the intended content of a developer-, admin- or content-authoring feature: code review, CI, API consoles, reporting queries, documentation and CMS editors, snippet stores, support tickets quoting code, AI coding-agent tool calls inside their granted scope. Not: Requests carrying real exploit payloads aimed at a sink belong to the matching attack class; Requests without attack-lookalike content belong to benign_standard_traffic, even when sent by a developer tool or an AI agent (an in-scope tool call with ordinary arguments is standard traffic); Lookalike text typed into an end-user search or filter box belongs to benign_hard_negative_search.
- `benign_hard_negative_search` (BENIGN): End-user search, filter or lookup text containing operators, quotes, markup or security keywords as ordinary user input (search boxes, catalog filters, help-centre and site search). Not: Search text carrying a real injection payload belongs to the matching attack class; Lookalike content in developer, admin or authoring features belongs to benign_hard_negative_dev; Search text with no lookalike tokens belongs to benign_standard_traffic.
- `benign_high_rate_legit` (BENIGN): High-rate legitimate flows such as CDN, backup, sync, streaming, and load-test traffic that resemble flood or scan patterns, and legitimate HTTP request bursts that resemble a race or flood (parallel reads, client retries under one enforced idempotency key, batch jobs) with a single effect on state. Not: Sustained floods with no legitimate service identity belong to syn_flood_ddos or udp_amplification; Sweeps across unrelated hosts belong to port_scan_recon.
